# 밤이 없는 나라 2 ~신월의 신부~ 한국어 패치

최신 누적 패치는 **2026.09.23 RC3 공개 시험판**입니다. 일본어 원문을 기준으로 교정하며 비타판은 비교 자료로 사용했습니다.

## 다운로드

- [RC3 다운로드 및 변경 내용](https://github.com/sirecoymarsh/nights-of-azure-2-korean-patch/releases/tag/v2026.09.23-rc3)
- [RC3 패치 ZIP](https://github.com/sirecoymarsh/nights-of-azure-2-korean-patch/releases/download/v2026.09.23-rc3/Nights_of_Azure_2_Korean_Patch_2026-09-23_RC3.zip)
- [사용법](README_KO.txt) · [SHA-256](SHA256SUMS.txt) · [검증 요약](qa-summary.json)

ZIP 전체를 게임 폴더 밖에 압축 해제한 뒤 **밤이 없는 나라 2 한국어 패치.exe**를 실행하세요.
게임 폴더를 자동 탐색하며, ‘패치 설치’와 ‘패치 복원’, 게임 시작·설정이 한 창에 있습니다.
런처 하단 ‘읽어주세요’에서 안내문을 다시 볼 수 있습니다.

이번 누적본은 이름 표기, 전투 잡담 물음표, 대사 개행, 동영상 자막 크기, 튜토리얼·메뉴 이미지와 마루부리 글꼴 수정을 포함합니다.

## 지원 및 복원

Windows 64비트 / .NET Framework 4.x, 확인된 PC판 파일 해시만 지원합니다. CHT 슬롯을 한국어로 사용합니다.
‘패치 복원’은 이 런처가 설치하기 직전의 상태로 되돌리며, 백업을 삭제하면 복원할 수 없습니다.
저장 데이터와 화면 설정은 설치·복원 대상에 포함되지 않습니다.
설치·복원 및 정적 검사를 통과했으며 실제 창 조작과 게임 플레이는 검수 중입니다.
