# 밤이 없는 나라 2 ~신월의 신부~ 한국어 패치

최신 누적 시험판은 **2026.09.24 RC8**입니다. RC7의 한국어 데이터 1,266개를 그대로 포함하며, GitHub 업데이트와 버전·설치 상태 표시를 추가했습니다.

- [RC8 다운로드 및 변경 내용](https://github.com/sirecoymarsh/nights-of-azure-2-korean-patch/releases/tag/v2026.09.24-rc8)
- [RC8 전체 패치 ZIP](https://github.com/sirecoymarsh/nights-of-azure-2-korean-patch/releases/download/v2026.09.24-rc8/Nights_of_Azure_2_Korean_Patch_2026-09-24_RC8.zip)

- [버그 제보 및 오역 수정](https://github.com/sirecoymarsh/nights-of-azure-2-korean-patch/issues/new/choose)

게임을 종료하고 ZIP 전체를 게임 폴더 밖에 푼 뒤 **밤이 없는 나라 2 한국어 패치.exe**를 실행하세요. 게임 폴더를 확인하고 **한국어 패치 설치** 또는 **한국어 패치 업데이트**를 누릅니다. 실제 파일이 모두 일치하면 **최신 패치 완료**가 표시됩니다.

**RC7 이하 런처 사용자는 RC8을 한 번 직접 내려받아야 합니다.** RC8부터 새 패치를 알림 후 한 번 클릭으로 내려받아 검증·백업·설치합니다. 시작할 때 사용자 동의 없이 설치하지 않습니다. RC7과 RC8의 게임 데이터는 같아서 RC7이 적용된 게임은 재설치하지 않아도 됩니다.

**한국어 패치 제거는 설치 직전 백업 상태로 되돌립니다.** 이전 한국어 패치 위에 설치했다면 그 패치가 남을 수 있습니다. 백업은 `%LOCALAPPDATA%\Noa2KoreanPatch\backups`에 저장되며 세이브와 화면 설정은 유지됩니다.

누적 수정에는 일본어 원문 대조 교정, 뮤벨·릴리아 표기, 전투 잡담 물음표, 대사 개행, 동영상 자막, 튜토리얼·메뉴 이미지, 마루부리 글꼴, 종마 무기·특수 배지와 어빌리티 포인트가 포함됩니다. 비타판은 비교 자료로 사용했습니다.

Windows 64비트 / .NET Framework 4.8 이상 / CHT 슬롯용입니다. **최신 순정 Steam판 실행과 실제 게임 화면의 최종 검수는 남아 있어 시험판으로 배포합니다.** 게임 설치본은 별도로 필요합니다.

기존 릴리스와 저장소 루트의 v1.0.1 ZIP 대신 위 RC8을 사용하세요.
