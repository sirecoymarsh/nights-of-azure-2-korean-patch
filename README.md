# Nights of Azure 2 한국어 패치

`v1.0.1` q 표시 수정 후보를 공개합니다. 기존 **CHT 슬롯**을 한국어로 교체하며 JPN/ENG 슬롯은 보존합니다.

## 다운로드
- `Nights_of_Azure_2_Korean_Patch_v1.0.1.zip`
- SHA-256은 `SHA256SUMS.txt`를 확인하세요.

## 설치
1. 게임을 종료합니다.
2. ZIP을 해제합니다.
3. `Install_Korean_Patch.bat`을 게임 폴더에 맞게 실행합니다.
4. 설치 후 새 저장을 사용하세요. 기존 세이브는 원본 슬롯/버전에 따라 호환되지 않을 수 있습니다.

## 복원
`Restore_Original.bat`을 실행하면 설치 전 백업으로 되돌립니다.

## 검증 상태
- CHT 슬롯 대상, JPN/ENG 보존
- 번역 맵 14,340행 고정
- ASCII `?` 표시 오류 0건; 의도적인 미공개 인물명 `？？？`는 유지
- 설치기/복원기 및 패키지 독립 감사 통과
- 내부 모델 정책: Codex 내부 모델만 사용

이 저장소에는 게임 원본이 포함되지 않습니다. 사용자가 보유한 정식 설치본에서만 사용하세요.
