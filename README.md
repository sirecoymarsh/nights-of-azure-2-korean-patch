# 밤이 없는 나라 2 ~신월의 신부~ 한국어 패치

최신 누적 시험판은 **2026.09.24 RC7**입니다. 누락된 UI를 한국어화하고, 원본 디자인에 맞춰 76개 이미지의 글자를 다듬었습니다.

게임을 종료하고 ZIP 전체를 게임 폴더 밖에 푼 뒤 **밤이 없는 나라 2 한국어 패치.exe**를 실행하세요. 자동 탐색한 게임 폴더를 확인하고 **패치 설치**를 누릅니다.
설치 전 파일을 모두 백업·검증한 뒤 덮어씁니다. **패치 복원은 설치 직전 상태로 되돌립니다.** 이미 다른 한국어 패치가 있었다면 그 상태로 돌아갑니다.
백업은 `%LOCALAPPDATA%\Noa2KoreanPatch\backups`에 저장됩니다. 세이브와 화면 설정은 유지됩니다.

이번 수정에는 종마의 무기·특수 배지, 어빌리티 포인트의 영어 표시, 버스트·스킬, 완료·실패, 포인트·이벤트·반복 등의 UI가 포함됩니다. 원래 초상화·아이콘·테두리와 애셋 크기를 보존했습니다.

일본어 원문 대조 교정, 뮤벨·릴리아 표기, 전투 잡담 물음표, 대사 개행, 동영상 자막, 튜토리얼·메뉴 이미지, 마루부리 글꼴 등 누적 **1,266개 파일**을 포함합니다. 비타판은 비교 자료로 사용했습니다.
Windows 64비트 / .NET Framework 4.8 이상, CHT 슬롯용입니다. **최신 순정 Steam판 실행 및 실제 게임 화면의 최종 검수는 남아 있어 시험판으로 배포합니다.**

게임 설치본은 별도로 필요합니다. 기존 RC5와 저장소 루트의 v1.0.1 ZIP 대신 위 RC7을 사용하세요.
