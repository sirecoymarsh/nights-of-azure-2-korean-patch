## 두 가지 업데이트

**패치 업데이트**는 번역·이미지 등 게임 데이터를 갱신합니다. **런처 업데이트**는 설치 프로그램을 갱신합니다. 새 버전은 백그라운드에서 확인하며, 버튼을 누르기 전에는 설치하지 않습니다.

1.0.6 이상부터는 같은 시작 파일을 계속 사용할 수 있습니다. 새 런처는 별도로 보관하고 정상적으로 열린 뒤 전환합니다. 실패하거나 저장된 새 런처가 손상되면 기존 시작 파일로 돌아옵니다. 1.0.3~1.0.5는 이 기능이 없으므로 새 런처를 한 번 직접 받아야 합니다.

### 편의 기능 (한국어 패치 런처)

원판에는 없는 전용 런처 `밤이 없는 나라 2 한국어 패치.exe`를 제공합니다 (RC3부터).

- **게임 폴더 자동 탐색**: 저장된 경로, 실행 중인 게임, Steam 설치 정보와 라이브러리, 로컬 드라이브의 Game·Games 폴더, 런처 주변 폴더를 확인합니다. 드라이브 전체를 뒤지지 않으며, 여러 설치본이 있으면 고르고, 직접 선택도 가능합니다 (`6fa03a7` README_KO.txt).
- **한 창 통합**: 원본 런처 그림과 버튼 배치에 게임 시작·설정(화면 모드·해상도)·상세 설정·한국어 패치 설치·제거·읽어주세요·버그 제보 및 오역 수정 메뉴를 통합했습니다. 원본 런처의 설치 경로 검사에 의존하지 않고 게임 실행파일을 직접 실행합니다. 게임을 시작해도 런처가 닫히지 않습니다 (`6fa03a7`, `v2026.09.24-rc8`).
- **설치 상태 표시**: 실제 게임 파일을 확인해 버튼이 「한국어 패치 설치 / 한국어 패치 업데이트 / 최신 패치 완료」로 바뀌고, 런처 상단과 메인 화면에 패치 버전을 표시합니다 (`v2026.09.24-rc8`).
- **게임 안 버전 표시**: 게임 창 제목과 타이틀 화면 하단에 적용한 한국어 패치 버전(예: `v2026.09.26-rc11`)을 표시합니다 (`v2026.09.24-rc9`).
- **패치 데이터 자동 업데이트**: GitHub 릴리스에서 새 데이터를 확인해 알려 주고, 사용자가 버튼을 누를 때만 서명·크기·SHA-256을 검증한 뒤 백업하고 설치합니다. 다운로드 중 취소할 수 있고, 오프라인이어도 기존 데이터로 설치·제거·실행이 됩니다 (`v2026.09.24-rc8`, `v2026.09.24-rc9`).
- **런처 자체 업데이트**: 1.0.6 이상은 오른쪽 위 「런처 업데이트」로 새 런처를 받아 사용자 계정의 전용 폴더에 버전별로 보관하고, 새 창이 정상적으로 열린 뒤 전환합니다. 실패·서명 불일치·손상 시 기존 런처로 돌아옵니다 (`launcher-v1.0.7`).
- **여유 공간 확인·백업 위치 변경**: 설치 전 실제 저장 위치(네트워크 드라이브·연결된 폴더 포함)의 남은 공간을 확인합니다. 백업 폴더를 다른 드라이브로 옮기려면 `%LOCALAPPDATA%\Noa2KoreanPatch\backup-root.txt`에 새 경로를 한 줄로 적습니다 (`v2026.09.25-rc10` 런처 1.0.3 노트, `launcher-v1.0.9`).

- **동영상 자막 오른쪽 쏠림**: 자막 493개를 조사해 465개(36개 파일)에서 줄 양끝 정렬용 공백을 지웠습니다. 공백까지 포함해 가운데 정렬하던 탓에 글자가 오른쪽으로 치우쳤습니다 (`v2026.09.24-rc5`).
- **어빌리티 포인트가 영어로 다시 나오던 문제** (`v2026.09.24-rc7`).
- **컬렉션 아이템 설명 겹침** (`v2026.09.24-rc9`).
- **RC9 시작 직후 종료(로고·영상 뒤 메인 메뉴 전에 꺼짐)**: 타이틀에 버전 문구를 넣으면서 UI 파일의 전체 항목 수·문자 항목 수를 갱신하지 않아 잘못된 메모리를 읽던 문제입니다. 두 값을 고치고 KSCL 42개의 항목 수 검사를 추가했습니다 (`v2026.09.25-rc10`, `d0a1c26`).
- **런처 버그**: RC4 긴 기본 백업 경로로 설치가 실패하던 문제(RC5), 정상 백업을 「설치 전 파일 목록이 손상되었습니다」로 잘못 판정하던 문제(런처 1.0.1), 게임 시작·설정 버튼마다 전체 검사를 반복해 1분 넘게 걸리던 문제(런처 1.0.3), 긴 연결 경로 잠금·중단 복구와 무관한 백업 오류(1.0.9), 창을 닫을 때 `Image.RawFormat / 매개 변수가 잘못되었습니다` 오류(1.0.10)를 고쳤습니다.

### 설치·제거 방식

- **현재(RC8 이후)**: 런처 ZIP을 게임 폴더 밖에 풀고 실행 → 게임 폴더 확인 → 「한국어 패치 설치/업데이트」. 런처가 서명된 데이터 ZIP을 내려받아 검증한 뒤 바뀔 파일을 `%LOCALAPPDATA%\Noa2KoreanPatch\backups`에 자동 백업하고 덮어씁니다(설치마다 약 1GB). 데이터 캐시는 `%LOCALAPPDATA%\Noa2KoreanPatch\data`입니다.
- **원본 판정**: v1.0.1~RC3는 확인된 PC판 원본 해시만 설치를 허용했지만, RC4부터는 원본 해시가 달라도 백업 후 덮어씁니다(패치·백업 무결성 검사는 유지). 각 파일마다 허용 해시 목록(`manifest.json` `accepted`)을 둡니다 (`9f69682`).
- **제거**: 런처 1.0.9부터 「한국어 패치 제거」는 한 단계 전이 아니라 **최초 원본 백업**으로 되돌리고, 패치가 새로 추가한 파일(5개)을 지웁니다. 원본 백업이 없거나 손상됐으면 파일을 바꾸기 전에 멈춥니다. 중단되면 같은 버튼으로 이어서 복원합니다. 그 전(RC4~1.0.7)에는 「설치 직전 상태」로 되돌렸습니다.
- **보존 대상**: 세이브와 화면 설정은 설치·제거 대상이 아닙니다. 제거 후 게임 언어는 원본 환경설정에서 다시 고릅니다.
- **수동 설치**: 데이터 ZIP의 `payload` 안 내용을 게임 폴더에 복사하고 `Nights of Azure 2_Settings.ini`의 `[Lang]`을 `Language=3`으로 바꿉니다(아래 「수동 설치」, `058e1a8`).
- **v1.0.1 방식(옛 판)**: `Install_Korean_Patch.bat`/`install.ps1 -GameRoot`로 원본 SHA-256 확인 → 백업 → 설치, `Restore_Original.bat`으로 복원했습니다 (`cb2fc50`). 저장소 루트의 `Nights_of_Azure_2_Korean_Patch_v1.0.1.zip`은 이 옛 판입니다.
- **지원 판본**: Windows 64비트, .NET Framework 4.8, Steam PC판 CHT 슬롯. PS Vita판·Switch판에는 설치할 수 없습니다 (`64c4239`). 게임 실행파일도 교체하므로 Steam 업데이트 후의 실행 호환성은 보장하지 않습니다.

### 알려진 문제

- RC11 게임 데이터는 아직 **시험판(pre-release)**입니다. 장시간 플레이 검수가 끝나지 않았습니다 (`qa-summary.json` `data_prerelease: true`).
- 최신 순정 Steam판에서의 실행 호환성은 검증하지 않았습니다. 패치가 게임 실행파일을 교체하므로 Steam 업데이트 뒤 문제가 생길 수 있습니다 (RC4~RC8 노트).
- 전투 중 축소 표시의 가독성, 타이틀 하단 버전 표시 위치, 오프닝 영상의 최종 화면은 사용자 확인이 남아 있습니다 (RC5·RC7·RC10 노트).
- 1.0.10으로 업데이트할 때 이미 열려 있던 구형 런처 창(1.0.9 이하)은 닫힐 때 이전 오류를 한 번 더 띄울 수 있습니다 (`launcher-v1.0.10`).
- RC9 데이터만 설치한 상태로 게임을 실행하면 시작 직후 종료됩니다. RC10 이상으로 업데이트해야 합니다.
- 기존 세이브는 원본 슬롯·버전에 따라 호환되지 않을 수 있다고 v1.0.1에서 안내했습니다 (`cb2fc50`, 이후 판에서 같은지는 (추정)).

## 수동 설치

런처가 게임 폴더를 찾지 못하거나 설치가 계속 실패할 때만 쓰세요. 직접 복사하면 런처 백업이 만들어지지 않습니다.

1. 게임을 종료합니다. 스팀판이 아니라면 게임 폴더를 먼저 따로 백업해 두세요.
2. [RC11 패치 데이터](https://github.com/sirecoymarsh/nights-of-azure-2-korean-patch/releases/download/v2026.09.26-rc11/Nights_of_Azure_2_Korean_Data_2026-09-26_RC11.zip)를 받아 압축을 풉니다. 런처에서 수동 설치를 고르면 같은 파일을 받아 폴더를 열어 줍니다.
3. `Nights_of_Azure_2_Korean_Data_2026-09-26_RC11\payload` 폴더 **안의 내용 전부**를 게임 폴더(`Nights of Azure 2_CHT.exe`가 있는 폴더)에 복사해 덮어씁니다. `payload` 폴더째 넣으면 적용되지 않습니다.
4. 게임 폴더의 `Nights of Azure 2_Settings.ini`를 메모장으로 열어 `[Lang]` 아래를 `Language=3`으로 저장합니다.
5. `Nights of Azure 2_CHT.exe`로 실행합니다.

되돌릴 때는 Steam에서 게임 파일 무결성 검사를 한 뒤 런처 1.0.10의 **한국어 패치 제거**를 누르세요. 패치가 추가한 파일까지 정리됩니다. 게임 언어는 원본 게임의 환경설정에서 다시 고르세요.

[버그 제보 및 오역 수정](https://github.com/sirecoymarsh/nights-of-azure-2-korean-patch/issues/new/choose)에 장·장소·실제 문구와 기대 동작을 남겨 주세요.
