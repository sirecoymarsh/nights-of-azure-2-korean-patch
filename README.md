# 밤이 없는 나라 2 ~신월의 신부~ 한국어 패치

최신 누적 시험판은 **2026.09.25 RC10**이며, 고정 런처는 **1.0.3**입니다.

**런처 1.0.3에서 게임 시작·설정·상세 설정이 1분 넘게 걸리던 문제를 고쳤습니다.** 설치 전에는 남은 공간을 확인합니다. RC10 패치 데이터와 기존 백업은 그대로 쓰므로 런처만 바꾸면 됩니다.

**RC9의 로고·영상 후 종료 오류를 수정했습니다.** 런처 1.0.3에서 **한국어 패치 업데이트**를 누르세요.

게임을 정상 종료한 뒤 런처를 실행하고 게임 폴더를 확인하세요. **한국어 패치 설치 / 한국어 패치 업데이트**를 누르면 GitHub의 데이터 ZIP을 내려받고 서명·파일 해시를 확인한 다음 백업하고 설치합니다. 데이터 ZIP은 직접 풀 필요가 없습니다. 이전 RC9 전체 패키지를 사용했다면 게임 실행 전에 RC10을 적용하세요.

**한국어 패치 제거**는 설치 전 백업으로 되돌립니다. 이전 패치 위에 설치했다면 그 패치로 돌아가며, 해당 백업이 남아 있으면 이어서 제거할 수 있습니다. 세이브와 설정은 유지됩니다.

일본어 원문 대조 교정, 뮤벨·릴리아 표기, 전투 잡담, 대사 개행, 동영상 자막, 튜토리얼·메뉴 이미지, 마루부리 글꼴, 종마 배지·어빌리티 포인트와 컬렉션 설명 수정 등 누적 1,266개 파일을 포함합니다.

RC10은 UI 항목 수 누락만 수정하고 게임 내 버전 문자열을 갱신합니다. RC9의 접근 위반을 재현한 환경에서 150초 실행 유지와 응답을 확인했습니다. 화면 하단 배치와 장시간 플레이는 사용자 확인이 남아 있습니다.

Windows 64비트 / .NET Framework 4.8 / CHT 슬롯용입니다. 게임 설치본은 별도로 필요합니다. 원작 이미지·브랜드의 권리는 각 권리자에게 있습니다. [마루부리 라이선스](LICENSE_MaruBuri.txt). 번역 및 UI 문구: Codex internal.
