게임을 종료하고 ZIP을 게임 폴더 밖에 풀어 **밤이 없는 나라 2 한국어 패치.exe**를 실행하세요. 게임 위치를 확인하고 **한국어 패치 설치** 또는 **한국어 패치 업데이트**를 누르면 됩니다.

**RC8에서 새 런처로 한 번 전환한 뒤에는 같은 런처를 계속 사용합니다.** 번역·이미지 수정은 GitHub 릴리스의 `Nights_of_Azure_2_Korean_Data_...zip`으로 제공되며 런처가 내려받아 서명·해시 검증 후 백업하고 설치합니다. 데이터 ZIP을 직접 풀 필요는 없습니다. 런처 기능 자체가 바뀔 때에만 새 런처가 필요할 수 있습니다.

**한국어 패치 제거**는 설치 전 백업으로 되돌립니다. 이전 패치 위에 설치했다면 그 패치로 돌아가며, 해당 백업이 남아 있으면 이어서 제거할 수 있습니다. 세이브와 설정은 유지됩니다.

일본어 원문 대조 교정, 뮤벨·릴리아 표기, 전투 잡담, 대사 개행, 동영상 자막, 튜토리얼·메뉴 이미지, 마루부리 글꼴, 종마 무기·특수 배지와 어빌리티 포인트 등 누적 수정 1,266개 파일을 포함합니다.

Windows 64비트 / .NET Framework 4.8 / CHT 슬롯용입니다. 게임 설치본은 별도로 필요합니다. RC9 게임 화면의 버전 표시·컬렉션 배치는 사용자 확인 전인 시험판입니다.
