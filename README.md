최신 패치 데이터는 **RC11**, 공개 런처는 **1.0.10**입니다.

- **처음 사용 / 런처 1.0.5 이하:** [런처 1.0.10 받기](https://github.com/sirecoymarsh/nights-of-azure-2-korean-patch/releases/download/launcher-v1.0.10/Nights_of_Azure_2_Korean_Launcher_1.0.10.zip) → 압축을 풀고 실행하세요.
- **런처 1.0.6 이상:** 오른쪽 위 **런처 업데이트**에서 새 버전을 설치할 수 있습니다.
- **게임 패치:** 런처에서 **한국어 패치 설치 / 한국어 패치 업데이트**를 누르면 RC11 데이터를 내려받아 검증·백업 후 설치합니다.

구형 런처의 종료 오류를 겪었다면 위 1.0.10 ZIP을 받아 실행하세요. 한국어 패치를 다시 설치할 필요는 없습니다.

## 두 가지 업데이트

**패치 업데이트**는 번역·이미지 등 게임 데이터를 갱신합니다. **런처 업데이트**는 설치 프로그램을 갱신합니다. 새 버전은 백그라운드에서 확인하며, 버튼을 누르기 전에는 설치하지 않습니다.

1.0.6 이상부터는 같은 시작 파일을 계속 사용할 수 있습니다. 새 런처는 별도로 보관하고 정상적으로 열린 뒤 전환합니다. 실패하거나 저장된 새 런처가 손상되면 기존 시작 파일로 돌아옵니다. 1.0.3~1.0.5는 이 기능이 없으므로 새 런처를 한 번 직접 받아야 합니다.

## 이번 변경

- RC11: 지도 지명 9개·숫자 아이콘 10곳의 간격 조정, 게임 창 제목과 타이틀 하단 버전 갱신.
- 런처 1.0.10: 창 종료 중 배경 이미지를 다시 그리다가 발생하던 오류 수정. 최초 원본으로 패치 완전 제거, 변경된 파일만 백업, 긴 연결 경로·무관한 백업 오류·여유 공간 처리 개선. 런처 자체 업데이트와 메뉴 응답성 개선은 유지합니다.
- RC10의 로고·영상 후 종료 오류 수정과 누적 번역·튜토리얼·메뉴·자막·컬렉션 수정은 유지했습니다.

게임을 저장하고 정상 종료한 뒤 패치를 설치하세요. **런처 1.0.10의 한국어 패치 제거**는 최초 원본 백업을 확인해 이전 한국어 패치까지 완전히 제거합니다. 원본이 없거나 손상됐으면 파일을 바꾸기 전에 중단합니다. Steam 무결성 검사 후 다시 제거하면 패치가 추가한 파일도 정리할 수 있습니다. 세이브와 화면 설정은 패치 대상에 포함하지 않습니다.

서명·파일 해시, 1,266개 파일의 설치·재설치·정확한 복구, 런처의 실패·취소 처리와 Defender 검사를 통과했습니다. 지도 화면 배치는 게임에서 확인했습니다. 장시간 플레이 검수는 진행 중이므로 RC11 데이터는 시험판으로 제공합니다.

## 수동 설치

런처가 게임 폴더를 찾지 못하거나 설치가 계속 실패할 때만 쓰세요. 직접 복사하면 런처 백업이 만들어지지 않습니다.

1. 게임을 종료합니다. 스팀판이 아니라면 게임 폴더를 먼저 따로 백업해 두세요.
2. [RC11 패치 데이터](https://github.com/sirecoymarsh/nights-of-azure-2-korean-patch/releases/download/v2026.09.26-rc11/Nights_of_Azure_2_Korean_Data_2026-09-26_RC11.zip)를 받아 압축을 풉니다. 런처에서 수동 설치를 고르면 같은 파일을 받아 폴더를 열어 줍니다.
3. `Nights_of_Azure_2_Korean_Data_2026-09-26_RC11\payload` 폴더 **안의 내용 전부**를 게임 폴더(`Nights of Azure 2_CHT.exe`가 있는 폴더)에 복사해 덮어씁니다. `payload` 폴더째 넣으면 적용되지 않습니다.
4. 게임 폴더의 `Nights of Azure 2_Settings.ini`를 메모장으로 열어 `[Lang]` 아래를 `Language=3`으로 저장합니다.
5. `Nights of Azure 2_CHT.exe`로 실행합니다.

되돌릴 때는 Steam에서 게임 파일 무결성 검사를 한 뒤 런처 1.0.10의 **한국어 패치 제거**를 누르세요. 패치가 추가한 파일까지 정리됩니다. 게임 언어는 원본 게임의 환경설정에서 다시 고르세요.
