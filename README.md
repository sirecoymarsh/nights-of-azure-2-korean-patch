# 밤이 없는 나라 2 ~신월의 신부~ 한국어 패치

최신 누적 시험판은 **2026.09.24 RC5**입니다. RC4의 긴 백업 경로 오류와 동영상 자막의 불필요한 공백을 수정했습니다.

- [RC5 다운로드](https://github.com/sirecoymarsh/nights-of-azure-2-korean-patch/releases/tag/v2026.09.24-rc5)
- [사용법](README_KO.txt) · [파일 해시](SHA256SUMS.txt) · [검증 요약](qa-summary.json)
- [버그 제보 및 오역 수정](https://github.com/sirecoymarsh/nights-of-azure-2-korean-patch/issues/new/choose)

게임을 종료하고 ZIP 전체를 게임 폴더 밖에 푼 뒤 **밤이 없는 나라 2 한국어 패치.exe**를 실행하세요. 자동 탐색한 게임 폴더를 확인하고 ‘패치 설치’를 누릅니다.
설치 전 파일을 모두 백업·검증한 뒤 덮어씁니다. ‘패치 복원’은 설치 직전 상태로 되돌립니다. RC3·RC4의 중단 기록이 있으면 복원을 먼저 실행하세요.
백업은 `%LOCALAPPDATA%\Noa2KoreanPatch\backups`에 저장됩니다. 세이브와 화면 설정은 유지됩니다.

일본어 원문 대조 교정, 뮤벨·릴리아 표기, 전투 잡담 물음표, 대사 개행, 동영상 자막, 튜토리얼·메뉴 이미지, 마루부리 글꼴 등 누적 1,257개 파일을 포함합니다. 비타판은 비교 자료로 사용했습니다.
Windows 64비트 / .NET Framework 4.8 이상, CHT 슬롯용입니다. **최신 순정 Steam판의 실행 호환성은 미검증**이며 실제 동영상 화면 검수도 남아 있어 시험판으로 배포합니다.

기존 RC4 및 저장소 루트의 v1.0.1 ZIP 대신 위 RC5를 사용하세요. 게임 설치본은 별도로 필요합니다.
