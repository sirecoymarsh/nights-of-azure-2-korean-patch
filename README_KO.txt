밤이 없는 나라 2 한국어 패치 런처 1.0.7

처음 사용하기
압축을 게임 폴더 밖에 풀고 ‘밤이 없는 나라 2 한국어 패치.exe’를 실행하세요.
1.0.3~1.0.5에는 런처 자체를 받는 기능이 없으므로 이번 버전은 한 번 직접 받아 실행해야 합니다.
한국어 패치 데이터는 RC11 기준입니다. 런처 1.0.6 이상은 오른쪽 위 ‘런처 업데이트’에서 1.0.7을 받을 수 있습니다.

두 가지 업데이트
‘패치 업데이트’: 번역·이미지 등 게임에 설치할 데이터를 확인하고 내려받습니다.
‘런처 업데이트’: 런처 프로그램의 새 버전을 확인합니다. 새 버전의 ‘설치’를 누르면 내려받아 새 창으로 전환합니다.
둘 다 실행 중 백그라운드에서 확인하며 버튼을 누르기 전에는 설치하지 않습니다.
런처만 업데이트할 때는 게임 파일, 저장 데이터, 화면 설정과 기존 패치 백업을 바꾸지 않습니다.

이후에는 같은 시작 파일을 계속 사용하세요.
새 런처는 사용자 계정의 전용 저장 폴더에 버전별로 보관됩니다. 기존 시작 파일을 열어도 마지막으로 정상 전환한 새 런처를 엽니다.
다운로드가 실패하거나 서명이 일치하지 않거나 새 창이 준비되지 않으면 기존 런처를 계속 사용할 수 있습니다.
새 런처 파일이 손상되거나 없어지면 기존 시작 파일로 돌아와 ‘런처 업데이트’를 다시 확인할 수 있습니다.
다운로드 중에는 취소할 수 있습니다. 새 창을 여는 동안에는 잠시 기다려 주세요.

한국어 패치 설치·제거
게임을 저장하고 정상 종료한 뒤 설치하세요. 설치 전 파일을 자동으로 백업합니다.
‘한국어 패치 제거’는 설치 직전 상태로 되돌립니다. 이전 한국어 패치 위에 설치했다면 이전 패치로 돌아갑니다.
게임 시작·설정 메뉴를 사용할 때마다 전체 검사를 반복하지 않습니다.

게임과 원본 저작권은 권리자에게 있습니다. 마루부리 라이선스는 LICENSE_MaruBuri.txt를 확인하세요.

이 ZIP에는 게임에 설치할 데이터만 들어 있습니다. 처음 사용한다면 별도로 제공되는 런처 1.0.7을 받으세요.
런처의 ‘한국어 패치 설치’ 또는 ‘한국어 패치 업데이트’를 누르면 이 데이터를 GitHub에서 자동으로 받아 검증·백업 후 설치합니다. 데이터 ZIP은 직접 풀 필요가 없습니다.
게임을 저장하고 정상 종료한 뒤 설치하세요. ‘한국어 패치 제거’는 설치 직전 상태로 되돌립니다. 이전 한국어 패치 위에 설치하면 제거 후 이전 패치가 남을 수 있습니다.

RC11 변경: 지도 지명 9개의 숫자 아이콘 10곳 간격 조정, 게임 창 제목·타이틀 하단 버전 갱신.
RC10의 시작 종료 오류 수정과 기존 번역·UI 수정은 유지했습니다. 지도 간격의 실제 게임 화면 최종 확인과 장시간 플레이 검수는 진행 중입니다.
