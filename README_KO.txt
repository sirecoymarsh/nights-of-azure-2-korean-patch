RC9에서 로고·영상 후 메인 메뉴에 들어가기 전에 종료되던 오류를 수정한 **RC10 데이터 업데이트**입니다.

타이틀 화면에 패치 버전 문구를 추가하면서 UI 파일의 전체 항목 수와 문자 항목 수가 갱신되지 않아 잘못된 메모리를 읽었습니다. 두 값을 바로잡고, 배포 대상 KSCL 42개의 항목 수 검사도 추가했습니다.

업데이트

- **런처 1.0.1은 그대로 사용합니다.** 게임을 정상 종료하고 런처를 다시 열어 **한국어 패치 업데이트**를 누르세요. GitHub에서 RC10 데이터만 내려받아 검증·백업 후 설치합니다.
- 처음 사용하거나 런처 1.0/RC8을 사용한다면 [고정 런처 1.0.1](https://github.com/sirecoymarsh/nights-of-azure-2-korean-patch/releases/download/v2026.09.24-rc9/Nights_of_Azure_2_Korean_Launcher_1.0.1.zip)을 받아 실행하세요.
- 게임 창 제목과 타이틀의 버전 문구는 `v2026.09.25-rc10`입니다.
- RC9 데이터를 단독으로 설치한 뒤 게임을 실행하지 말고 RC10으로 업데이트하세요. 런처 1.0.1만 교체해도 이번 게임 데이터 오류는 남아 있습니다.

검증

- 누적 1,266개 파일 중 변경 대상은 게임 창 버전 문자열과 타이틀 UI 파일, 총 2개입니다. 게임 코드·기존 이미지·번역·컬렉션 수정은 유지합니다.
- RC9 오류를 동일 위치에서 재현했고 RC10 복사본은 150초 동안 접근 위반 없이 실행·응답했습니다. 입력 자동화와 강제 종료는 하지 않았습니다.
- 실제 배포 런처 1.0.1로 서명 확인, 최종 ZIP 설치, 1,266개 해시 확인, 설치 전 상태의 정확한 복원을 검증했습니다.
- 수정 EXE·배포 폴더·최종 ZIP·압축 해제 사본 Defender 검사와 독립적인 읽기 전용 검토를 통과했습니다.

화면 하단 버전 표시의 위치와 장시간 플레이는 사용자 확인이 남아 있어 시험판으로 제공합니다. 저장 데이터·설정·기존 원본 백업은 패치 대상에 포함하지 않습니다.


밤이 없는 나라 2 ~신월의 신부~ 한국어 패치

처음 사용할 때
압축을 게임 폴더 밖에 풀고 ‘밤이 없는 나라 2 한국어 패치.exe’를 실행하세요.
게임 폴더를 자동으로 찾습니다. 여러 설치본이 있으면 사용할 폴더를 선택하세요.
게임을 저장하고 정상 종료한 다음 ‘한국어 패치 설치’를 누르세요.

이후 업데이트
이 런처는 GitHub 공개 릴리스의 데이터 ZIP을 내려받아 같은 창에서 설치합니다.
새 버전이 있으면 ‘한국어 패치 업데이트’를 누르세요. 자동 설치는 하지 않습니다.
번역·이미지만 바뀔 때는 런처 실행파일을 다시 받을 필요가 없습니다.
다운로드 크기·SHA-256·데이터 서명과 모든 설치 대상 파일을 확인합니다.
다운로드 중에는 취소할 수 있습니다. 설치·제거 중에는 완료될 때까지 기다려 주세요.
인터넷 연결에 실패해도 기존 데이터로 실행·설치·제거할 수 있습니다.
런처 기능 자체가 바뀌는 경우에만 새 런처가 필요할 수 있습니다.

표시와 백업
메인 화면 버전은 이 런처가 선택한 패치 데이터 버전입니다.
‘최신 패치 완료’는 게임 파일이 해당 데이터와 모두 일치한다는 뜻입니다.
오프라인에서는 GitHub의 최신 여부를 보장하지 않습니다.
게임의 제목줄과 타이틀 화면 하단에는 실제 적용한 패치 버전이 표시됩니다.
설치 전에 바뀔 파일을 자동 백업합니다. ‘한국어 패치 제거’로 설치 직전 상태로 되돌립니다.
이전 패치 위에 설치했다면 제거 후 이전 패치로 돌아갑니다. 다시 제거해 이전 백업도 복원할 수 있습니다.
저장 데이터와 화면 설정은 제거하지 않습니다. 실행 중인 게임을 강제로 종료하지 않습니다.
백업: %LOCALAPPDATA%\Noa2KoreanPatch\backups
데이터 캐시: %LOCALAPPDATA%\Noa2KoreanPatch\data
