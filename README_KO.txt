밤이 없는 나라 2 ~신월의 신부~ 한국어 통합 런처
2026.09.23 검토 후보 (RC3 · 읽어주세요 / 제보 메뉴)

1. ZIP 전체를 게임 폴더 밖의 짧은 경로에 풀어 주세요.
2. ‘밤이 없는 나라 2 한국어 패치.exe’를 실행합니다.
3. 게임 폴더를 자동으로 탐색합니다. 하나를 찾으면 바로 선택되며, 여러 개면 사용할 설치본을 고릅니다.
   찾지 못했거나 다른 폴더를 쓰려면 ‘게임 폴더 직접 선택/변경’을 누릅니다.
4. 게임을 정상 종료한 뒤 ‘패치 설치’를 누릅니다.
5. 완료 후 ‘게임 시작’을 누릅니다. ‘설정’에서 화면 모드와 해상도를 바꿀 수 있습니다.

원본 그림과 버튼 배치에 게임 시작·설정·패치 설치·패치 복원을 통합했습니다.
원본 런처의 설치 경로 검사에 의존하지 않고 게임 실행파일을 직접 실행합니다.
언어는 한국어 슬롯으로 선택하며, 저장된 화면 모드와 해상도를 임의로 초기화하지 않습니다.
상세 환경설정을 열었다면 그 창을 닫은 뒤 게임을 시작해 주세요.

이번 후보에는 현재까지의 누적 한국어 파일 1,257개가 포함되어 있습니다.
일본어 원문 대조 교정, 뮤벨·릴리아 이름 정리, 전투 잡담 물음표,
대사 흐름·동영상 자막 크기·튜토리얼·메뉴 이미지·글꼴 수정을 포함합니다.
비타판은 비교 참고 자료로만 사용했습니다. 번역 및 UI 문구: Codex internal.

지원 범위
Windows 64비트 / .NET Framework 4.x용입니다.
정확한 파일 해시가 확인된 PC판과 기존 v1.0.1/이번 후보 파일만 설치를 허용합니다.
다른 판본이나 알 수 없는 수정이 있으면 파일을 바꾸기 전에 중단합니다.
설치 상태를 확인하는 동안 시간이 걸릴 수 있습니다.

복원
‘패치 복원’은 이 런처가 설치하기 직전의 파일 상태로 되돌립니다.
다른 패치 위에 설치했다면 그 이전 패치 상태로 돌아갑니다.
저장 데이터와 화면 설정은 설치·복원 대상에 포함되지 않습니다.
백업은 %LOCALAPPDATA%\Noa2KoreanPatch\backups에 저장됩니다.
복원이 필요할 수 있으므로 이 폴더를 지우지 마세요.
중간에 종료되었으면 다시 런처를 열고 ‘패치 복원’을 먼저 실행하세요.
복원은 패치 payload가 없어도 런처와 외부 백업으로 처리할 수 있습니다.

이미 같은 한국어 파일이 적용된 개발·검토용 게임에서는 재설치할 필요가 없습니다.
이 런처로 만든 백업이 없다면 복원 버튼은 기존 개발 백업을 가져오지 않습니다.
그 경우 이전 작업에서 보관한 복원 기록을 사용해야 합니다.

검증 범위
원본 사본 설치·바이트 일치 복원, 알려진 혼합 상태, 변조 거부,
교체 실패·중단 복구, 설정 보존 및 배율별 비표시 렌더를 시험했습니다.
이 후보의 실제 게임 실행과 창 조작은 아직 사용자 확인 전입니다.
게임 원작의 이미지·브랜드·저작권 표기는 유지합니다.
글꼴 출처와 라이선스는 LICENSE_MaruBuri.txt를 참고해 주세요.

오른쪽 위 X 또는 하단 ‘런처 종료’로 닫을 수 있습니다. Alt+F4와 Esc도 지원합니다.
게임 폴더 탐색 중에도 닫을 수 있으며, 파일을 실제 교체하는 동안에는 완료·복구를 기다립니다.

자동 탐색은 저장된 경로, 실행 중인 게임 위치, Steam 설치 정보와 라이브러리,
로컬 드라이브의 Game·Games 폴더 및 런처 주변 폴더를 확인합니다.
실행파일과 필수 데이터 폴더가 함께 있는 위치만 후보로 잡으며, 드라이브 전체를 재귀 검색하지 않습니다.
Steam 위치 탐색과 해당 설치본의 패치 호환성은 별개이며, 설치 전 파일 검증은 그대로 수행합니다.
